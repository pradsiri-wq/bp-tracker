เชื่อมต่อ Google Drive

แอปจะสร้างไฟล์ bp-data.json ใน Drive ของคุณ และบันทึกอัตโนมัติทุกครั้งที่เพิ่มหรือลบข้อมูล (เห็นเฉพาะไฟล์ที่แอปนี้สร้าง)

  1. เข้า console.cloud.google.com สร้างโปรเจกต์ แล้วเปิดใช้ Google Drive API
  2. ไปที่ APIs & Services → Credentials → Create credentials → OAuth client ID ประเภท Web application
  3. ใน Authorized JavaScript origins ใส่ที่อยู่ที่คุณเปิดแอป:
  4. คัดลอก Client ID มาวางด้านล่าง แล้วกดบันทึก
